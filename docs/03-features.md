## Решения по вопросам этапа

1. Языки интерфейса — русский, английский, азербайджанский. Документы для Азербайджана — на азербайджанском.
2. Остаток трудового отпуска система считает сама.
3. Сверх свободных ставок — только предупреждение.
4. В карточке — только данные документов, без сканов.
5. Формы оплаты: оклад, оклад + премиальная часть, сдельная, почасовая.
6. Интеграция с государственной системой регистрации договоров не нужна сейчас — только отметка о регистрации.
7. История изменений нужна в первой версии.
8. Оплата — всегда в валюте страны филиала (для Азербайджана — AZN).
